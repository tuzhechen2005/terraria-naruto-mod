# M1：波之国下忍篇

这是第一个大阶段目标：玩家使用新角色和新世界，不依赖 `/m0` 测试命令，沿一条自然的忍者成长路线完成白与再不斩的战斗。

## 玩家流程

1. 开局获得任务卷轴和基础苦无，完成简短的战斗训练。
2. 通过探索与雾隐侦察兵遭遇，取得情报和制作材料。
3. 用 Terraria 的采集与制作系统准备装备和白的挑战卷轴。
4. 击败白，取得挑战再不斩的线索或道具。
5. 击败再不斩，完成波之国篇，解锁下一篇章的入口。

## 验收标准

- 新角色能看懂下一步做什么，完成流程时不需要开发者命令或外部攻略。
- 两场 Boss 都采用人形尺度，预警与受击判定可读；白与再不斩的战斗节奏有明显区别。
- 木材、矿石和战利品至少形成一条制作链，原版 Boss 不构成主线门槛。
- 任务进度与 Boss 击败状态在退出并重新进入世界后仍保留。
- 单人流程首先完整可玩；多人同步在本阶段后单独验证。

## 开发顺序

先做开局任务与成长提示，再加入雾隐侦察兵和制作链，然后完成白的战斗与两个 Boss 的衔接。最后整理地图场景、中文文本、奖励和引导，进行从新档开始的完整试玩。

M0 的 `/m0` 保留为开发测试入口，不参与正式流程。美术可继续使用临时素材，但任务引导、战斗预警和流程不能依赖占位说明。
