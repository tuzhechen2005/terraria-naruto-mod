# Terruto 中文百科

参考 Terraria 官方 Wiki 与灾厄 Wiki 的游戏百科布局：木叶/火影岩场景背景、顶部标识、深色土色面板、金色边框和青绿色词条链接。道具目录按八类展示图标与属性表格。静态网站，覆盖当前波之国与中忍考试内容。支持中文全文搜索、分类筛选、独立词条、属性框、配方、源码依据与 Boss 推进路线；电脑与手机均可使用。

## 本地查看

在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory wiki/site
```

浏览器打开 `http://127.0.0.1:8765/`。已经生成的页面无需 Node.js、数据库或联网服务。`wiki/site/` 整个目录可作为静态站点发布；尚未配置公开托管。

## 更新内容

- `content.py`：人工核对的中文说明、分类、关联词条与源码路径。
- `build.py`：提取源码基础属性、首领生命与防御常量，导出运行时贴图并生成页面。图片只导出当前已经接入模组的贴图，后台交付不自动接入百科。
- `style.css`、`app.js`：排版、搜索、分类过滤与移动导航。
- `site/source-manifest.json`：构建依赖文件的 SHA-256，用于检测百科整理后源码或贴图变化。
- `check.py`：检查所有内部链接、图片路径、页面锚点与源码变化。

生成需要 Python 3 与 Pillow。可在独立虚拟环境安装 Pillow，也可使用 Codex 提供的工作区 Python。

```sh
python3 wiki/build.py
python3 wiki/check.py
```

模组改变后，先检查 `check.py` 报告的 `STALE` 文件，核对对应说明，再重新构建。**构建只能同步可提取属性与图片，不会替代人工核对流程和掉落。** 基础属性不包含游戏难度、装备修饰和角色加成。页面源码链接固定到构建时的本地提交，该提交推送前 GitHub 链接可能尚不可访问。

样式、交互脚本、搜索索引和词条贴图均带内容哈希；重新生成后刷新页面即可加载最新资料。

## 收录边界

当前 70 个词条：33 道具、7 首领/战斗、7 人物、3 敌怪、5 地区、8 机制、7 指南。规划中的 M3、后续瞳术与尾兽单列为开发路线；M0 测试物品、旧版自动转换物品不列入正常获取图鉴。已实现的豪火球与千鸟卷轴列为“开发试用”，写明正常获取尚未接入；分身术开局自带。仙术核心未列为当前可获得物品。

百科更新只涉及文档与展示素材，没有改变模组代码。网页检查不等于游戏内验收。保留模组已有版权与许可说明，不导出本地原声音乐。
