## 1. 验收条件与证据

- 使用克眼后推荐配装、200 生命的普通模式角色，记录职业、装备、防御、武器、替身资源、游戏缩放和场地布局。不使用开发者翅膀、无敌或后期机动验证基础可躲性。
- 分别记录单人、多人、专家/大师的结果，不将普通模式结果扩展到其他难度。
- 每项填写版本/提交、执行方式、结果、录像或日志位置、未解决问题。伤害验证记录防御前目标值与实际扣血，保留原版浮动口径。
- 手感、华丽程度、基础跑跳可躲性、近战可达性与性能须实机确认；规则测试仅覆盖相应状态和计算。
- 后续实施者若改变参数，在设计第 12 节或实施记录中注明原因；不得更改已定稿方向来让清单通过。

## 2. 双首领结构与异常（阻断项）

- [ ] S01 开场只有再不斩；普通伤害、非致死跨半血大伤、致死大伤及多人同帧命中均只触发一次转场，转场前生命不越过半血。
- [ ] S02 白在转场中登场、结束后才攻击；两人转场保护正确，原版独立血条与头像正常。
- [ ] S03 受阻落点与 NPC 槽满有可恢复或可靠中止路径，不能永久卡住、重复生成白或允许缺席白时获胜。
- [ ] S04 白先死与再不斩先死两条路径均正确：幸存者暴走一次、不补血、不提前发通关奖励。
- [ ] S05 同场两次真实死亡后只结算一次；同时死亡事件有服务器确定的统一顺序，不强制追加暴走出招。
- [ ] S06 离屏、非死亡失活、链接异常与生成失败均不计为击杀；跨区域移动不重置本战身份或死亡记录。
- [ ] S07 全部参战玩家死亡后，攻击、镜子、边界、无敌/隐身状态与未完成尾声全部清理，下次从一阶段重开。仍有存活参战者则继续。

## 3. 体量、移动与伤害判定（阻断项）

- [ ] B01 同屏正常缩放测可见身高：再不斩约 3H、白约 2.5H；H 为玩家可见高，排除武器、鬼影、镜子和透明画布。
- [ ] B02 站立、跑跳、持刀、投针、瞬身和暴走帧的脚底/身体锚点稳定；放大后的躯干受击区域合理，不把光晕和鬼影当身体。
- [ ] B03 普通身体重叠、白自由换位与镜间穿梭不扣血；刀锋及口咬苦无局部判定与可见部位对应，左右朝向均正确。
- [ ] B04 一次短连段、水龙、突进对每名玩家按施放身份去重；替身挡下仍消耗本次命中，身体与武器不叠伤。
- [ ] B05 暴走投刀去、回每程各至多一次命中，回程可见；旋转尾迹不追加伤害。
- [ ] B06 再不斩通过跳跃、空中突进、主动水雾瞬身追击平台和高度差，普通移动保持落脚感；落点先提示、现身重新起手，不能无预警贴脸伤人。
- [ ] B07 白可飞行/穿地形换位；停留投针时可打，不长期躲在墙后无效射击；巨型本体在斜坡与狭窄落点不永久卡住。

## 4. 核心攻击、镜阵与反击（阻断项）

- [ ] A01 刀术短连段的节奏、改变方向提示、最大末击和收招可辨；基础跑跳能应对，不要求跳过整个巨大身体。
- [ ] A02 水龙释放前路线清楚、发射后不追踪，穿平台/实心；穿墙仍见预警与危险轮廓，龙身判定对应危险主体，消散水花无伤害。
- [ ] A03 白自由模式完整呈现换位、停留预警、一轮千本、恢复、换位；普通针穿单向平台、碰实心消散，碰地冰晶无追加伤害。
- [ ] A04 常态牢笼定点、限时，边界先显示后生效；现有平台方块保留，不随玩家一路移动。
- [ ] A05 镜内白受保护，现身/穿梭可打；有效出手镜先亮起，被打碎后不能继续出针，改选镜重新预警。
- [ ] A06 打碎规定数量提前破阵；自然超时也可靠结束。先按 8 面、破 4 面初值验收，调整则记录实际值。
- [ ] A07 自然结束给短收招；主动破阵提供更长硬直和短暂易伤，普通跑跳可接近白并输出，效果可辨。
- [ ] A08 近战、远程、魔法、召唤都能合理破镜；召唤物能选择有效镜子，不只追无敌白。
- [ ] A09 镜阵与破阵奖励窗口期间再不斩不造成伤害；奖励结束后通过可见预警接棒，不抢掉输出时间。

## 5. 合击与两种暴走（阻断项）

- [ ] C01 统一主攻权使独立强招互斥；白自由主攻时再不斩不突然贴脸连段，普通辅助针不封掉主攻的安全路线。
- [ ] C02 合击只在白自由模式、二人存活且无镜阵/奖励窗口时出现，不频繁堆叠。
- [ ] C03 水龙先逼换层，白独立预警后覆盖部分落点；常规平台场地至少有基础跑跳可达的安全路线，区域锁定后不追补安全区。
- [ ] C04 合击不追加刀术、第二水龙或镜阵；结束双方收招。死亡、目标失效或失败时后续步骤取消，危险实体按状态清理。
- [ ] R01 白先死后再不斩舍弃水遁，以凶狠连段、投刀和口咬苦无追击；鬼影/接刀演出加强，起手与收招仍明确。
- [ ] R02 再不斩先死后白使用缓慢跟随的持续镜环；损坏镜延迟重生，不沿用普通牢笼推回边界，不让破镜造成无限硬直。
- [ ] R03 暴走白仍有现身/穿梭可打窗口；低血千杀水翔有预警、可辨缺口和恢复，不用铺满弹幕取代难度设计。
- [ ] R04 暴走、加速与多人环境下，高伤害强招可见提示到判定仍至少 24 帧，瞬间近身至少 15 帧。

## 6. 华丽特效与可读性（实机阻断项）

- [ ] V01 人物保留像素造型；水龙主体、冰镜和查克拉符合动画式流体与柔光方向，未被改回全硬边像素或仅外围可柔光。
- [ ] V02 普通刀术有流动刀光/轨迹，千本有亮针尖/冰痕，换位有残像；在正常游戏尺寸下可见。
- [ ] V03 水龙从聚势、龙头/龙身释放到水花崩散完整；镜阵逐面结晶、剪影、亮镜与破碎完整；合击两步有独立颜色和声音。
- [ ] V04 暴走鬼影、旋转刀迹、接刀冲击、强化寒光和悬浮针阵明显升级；外围光效与余波无隐含伤害。
- [ ] V05 明暗背景、实心障碍、多层平台和多人叠加下，预警、危险主体、玩家与血条/UI 都清楚。
- [ ] V06 仅选定重击节点轻微短震、少数强招短压暗；普通针和轻斩不持续震屏，不强制锁镜头。
- [ ] V07 柔光/寒气素材保留半透明边缘，没有走人物二值 alpha 或限色管线；翻转后轨迹与判定对应。
- [ ] V08 同机器/场景/缩放记录特效开关前后的帧时间与资源；多次战斗后临时实体归零、资源不无限增长，离屏装饰可减量但预警/危险主体保留。

## 7. 建造、追击与尾声（阻断项）

- [ ] W01 大桥提供基本通行和少量落脚点；开战不重刷三层竞技场、不清方块，不新增永久大型专属场景或子世界。
- [ ] W02 自建平台、墙体与建筑全程保留；水遁不依赖当地真实水体，千本仍可被墙挡。
- [ ] W03 开战后跨海岸、其他生物群系、远离大桥、离屏与天亮仍追击；存在存活目标时无默认退场误判或距离桥强制重置。
- [ ] W04 狭窄洞穴保留完整招式，玩家承担空间不利；预警、判定、镜阵超时与失败清理仍可靠。
- [ ] E01 两条死亡顺序分支保留已有台词/动作、雪和音乐，地点在最后击杀附近；近且同地面时自然衔接。
- [ ] E02 两次击杀相隔很远、隔实心墙、上下高差、水下或危险液体时，通过短过渡整理两人安全位置，再播正确分支。
- [ ] E03 第一具尸体离屏、消失或超时后仍可按死亡记录恢复；无自然落脚处的兜底不改方块或生成永久平台。
- [ ] E04 不传送玩家、不锁输入；玩家离开尾声不阻断已获胜进度，卡卡西后续能找到有效玩家，音乐在实际尾声区域生效。
- [ ] E05 桥完工、奖励、解锁在桥外胜利后仍只触发一次；原脚手架位置被玩家替换为同材料时不误拆自建方块。

## 8. 平衡、联机与回归

- [ ] P01 四职业按同期配装完成两种击杀顺序；记录熟悉后战斗时长，目标 3–4 分钟、不计尾声，不靠无敌等待凑时长。
- [ ] P02 在基本开阔空间仅用普通跑跳验证关键刀术、水龙、针与合击可躲；平台、跑鞋/二段跳/钩爪/替身有收益但不是必备条件。
- [ ] P03 初见经过数次尝试可以掌握，少量失误可恢复；记录实际扣血、回血机会、破镜效率和死亡原因后调参。
- [ ] P04 普通防御前目标伤害按设计表和 EnemyDamage 工具口径；普通/持续招上限 30、强招上限 60，内部倍率不重复处理。
- [ ] N01 服务端唯一生成白、镜子、攻击、奖励；客户端阶段、已锁路线、镜阵槽位与中心、死亡序、尾声锚点一致。
- [ ] N02 多人分开远行、目标死亡或切换后，合击取消或重新完整预警；镜阵目标不无提示换人，队友可从外破镜。
- [ ] N03 局域网与延迟环境分别验证预警先于伤害；重连/异常退出无残留或重复结算，记录各自结果。
- [ ] N04 旧档双通关、旧单人标志处理、旧白卷轴转换、重复挑战、首杀与重复掉落、原版血条/头像均回归。
- [ ] N05 新提示与手册内容进入中英 Localization，键与占位符一致；缺少本地音乐时回退有效，公开交付不包含版权原声。
- [ ] T01 为半血锁线、真实击杀账本、主攻互斥、命中去重、生成异常和死亡分支编写/更新有意义的规则测试并运行。
- [ ] T02 运行 `./scripts/verify-mac.sh`，记录规则/文本检查与完整构建结果；无头加载适用时另记结果，单人/联机实测独立记录。
