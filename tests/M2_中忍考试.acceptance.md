# M2 中忍考试篇 验收用例

对应规格：[M2 中忍考试篇](../specs/M2_中忍考试篇.spec.md)（2026-09-30 定稿），立志见 [流派系统](../specs/流派系统.spec.md) 第六节。旧方案（报名书合成、原创砂隐考生）已作废，旧用例删除。状态：**游戏内测试未执行**；Boss 与三代为占位贴图。

前提：**新建的世界**（有木叶、演习场入口、中央塔、考试会场）；进游戏前先 Build + Reload。测试捷径：`/m0 exam` 查看阶段与场地坐标，`/m0 exam <阶段>` 跳到某阶段（单人），`/m0 exam gate|tower|stadium|academy|hokage` 传送。

| ID | 级别 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| E01 | 阻断 | 击败再不斩与白，等尾声对白结束。 | 卡卡西瞬身出现在身边，戏谑地说把你的名字报上去了，交出推荐书；任务目标变为笔试。推荐书丢了找他补发。 |
| E02 | 阻断 | 在忍者学校外、学校里分别使用推荐书。 | 学校外提示去学校；学校里打开笔试面板：9 道四选一 + 第十题。 |
| E03 | 阻断 | 答完九题，第十题选“接受”。 | 合格，按答对题数得银币；目标变为去第四十四演习场入口。 |
| E04 | 非阻断 | 另一角色第十题选“放弃”，当天再用推荐书；过一夜再用。 | 当天被拒；天亮后可重考。 |
| E05 | 阻断 | 走到丛林边的演习场入口。 | 自动领到天之卷或地之卷，有提示；入口铁丝网、大门、告示可见，能直接走过去。 |
| E06 | 阻断 | 领卷后在丛林地表击败一队考生，再往中央塔附近走。 | 雨隐三人组伏击（先有雨声提示，出现时大字写“雨隐三人组”）；击败三人后得到缺的那一卷。没打过考生时不会出现。 |
| E07 | 非阻断 | 用 `/m0 exam ForestHunt` 后远离中央塔，只打考生小队。 | 考生三人一组出现；按概率掉卷，第 5 队必掉。 |
| E08 | 阻断 | 带齐两卷进入中央塔大厅。 | 第二试合格提示；随后监考官宣布预选赛，多斯从大厅另一端出现。 |
| E09 | 阻断 | 与多斯交手，挨一次响鸣穿。 | 响鸣穿有蓄力提示；挨中后左右颠倒不超过 2 秒并有屏幕晃动；音波把人推开。击败后预选合格。 |
| E10 | 阻断 | 未打骷髅王、生命 < 400 时查看目标；达到任一门槛后再看。 | 先要求变强；达标后目标变为去考试会场。 |
| E11 | 阻断 | 进入会场场地。 | 主考官宣布，我爱罗出现。 |
| E12 | 阻断 | 与我爱罗交手：正面攻击、绕背攻击、他出招后的空档攻击。 | 正面大幅减伤并显示“沙之盾”，背后与空档伤害正常；半血后沙浪、四分之一血后沙臂与练空弹，外观变化。 |
| E13 | 阻断 | 被沙缚柩抓住后按替身术；另一次不按。 | 按替身术立刻脱身；不按则被沙瀑送葬重击。 |
| E14 | 阻断 | 击败我爱罗。 | 得到中忍护额；全服提示木叶崩溃开始（M3 开发中）；任务显示中忍考试篇完成。 |
| E15 | 非阻断 | 正式赛开始后找卡卡西，在会场用宁次的切磋书。 | 得到切磋书；宁次出现。被柔拳打中叠点穴，查克拉上限降低，满 3 层替身术封住；回天时射出的弹幕消失；站在八卦圈里挨六十四掌。可重复挑战。 |
| E16 | 非阻断 | 打过世吞或克脑（或生命 ≥ 300），带卷轴在丛林地表。 | 先有“林子忽然安静”的提示，一名“考生”走近，变身解除成大蛇丸（此时大字出现名字与身份），杀气定身，替身术可挣脱；潜影蛇手、蛇行突进、大突破、五行封印（约 8 秒查克拉不恢复）、长颈、通灵蛇都有预警。打到半血锁血、台词、化蛇离开，掉蛇的蜕皮，约 1/4 掉写轮眼试管；蜕皮也可合成，在丛林地表召唤。 |
| E17 | 阻断 | 第一次拿到流派核心后。 | 卡卡西在聊天框传话“三代叫你去火影楼”；三代的开场白提到这件事；戴着核心点立志即完成；改投需 10 金币并二次确认；立志时提示仙术要到 M3。 |
| E18 | 阻断 | 在没有木叶的旧世界完成波之国后找卡卡西。 | 说明中忍考试需要新世界；其余内容照常。 |
| E19 | 阻断 | 各阶段保存退出、死亡后重进。 | 进度不丢失、不锁死；卷轴丢失时考生仍会掉。 |
| E20 | 非阻断 | 两人联机：一人推进考试、另一人旁观或参战。 | 考试进度各自独立；参战者各自获得卷轴与合格；Boss 击败按世界记录。 |
| E21 | 阻断 | 分别用音忍的对战牌（塔内大厅）、砂隐的葫芦（会场）、蛇的蜕皮（丛林地表）、宁次的切磋书（会场）。 | 各自召唤对应 Boss；地点不对或进度没到时有说明；都不消耗。 |
| E22 | 阻断 | 首次击败我爱罗；再用葫芦击败一次。 | 首杀必得八门遁甲之卷与小李的负重护腿；之后按概率。 |
| E23 | 阻断 | 分别戴写轮眼试管、八门之卷、白眼，按 V。 | 写轮眼：看破后 4 秒内第一次受击自动替身，替身判定窗口变长；八门：每按一次开一门，掉血、变快，三门再按关门，低于 20% 生命自动关门；白眼：看得见敌人，近战叠点穴，回天抵消弹幕并弹开敌人。同时只能戴一个核心。 |
| E24 | 非阻断 | 用训练用绷带（木材 + 丝绸）和负重护腿战斗，开八门后再打。 | 每拳打出风压，贴身更痛；右键冲刺踢短暂无敌；开门后风压变大变远。 |
| E25 | 非阻断 | 模组设置打开“任务追踪”，走过几个阶段。 | 查克拉条下显示任务与方向距离；默认关闭时只有手册和卡卡西的提示，任务文本只写大概方向。 |
| E26 | 非阻断 | 打开手册“首领”页；装 Boss Checklist 时查看清单。 | 列出每个火影首领的地点、召唤方式、掉落与是否击败；清单里有大蛇丸、多斯、我爱罗、宁次。 |

## 2026-10-01 改版（全部未执行）

- E27 新世界：入口大门、监考小屋、红豆在小屋前；森林深处的中央塔离入口足够远；沿路有空心巨树（树洞宝箱）、警告牌，没有林中休息处（旧世界 rebuild 后也被清掉）。`/m0 exam rebuild` 能在旧世界原地重建。
- E28 找红豆领卷：未笔试合格时不给；领卷后不再自动发。
- E29 过大门约 40 格遭考生小队伏击；打完一句暗示；不会重复；跑掉后回来会再伏击。
- E30 塔前空地：雨隐三人组的千本雨有落点闪光、分身打中即消失；最后一人倒下给缺的卷；已有两卷时不出现。
- E31 游荡小队只在第一个节点之后出现，不掉卷、不发消息；凑齐两卷后不再来。
- E32 找疾风开始预选赛；打输后可以再找他；进大厅不会自动开打。
- E33 多斯五招都会出现，不连续重复；半血后明显加快，音波连发两道；共鸣环只有环本身伤人。
- E34 所有 Boss 出场没有大字标题；大蛇丸不会在丛林里自己出现。
- E35 新/旧世界：雾隐侦察兵不再出现；见过达兹纳后进海雾遭鬼之兄弟伏击；达兹纳坦白时给 1 枚雾隐标记。
- E36 Boss 与杂兵不会卡在墙里或小坑里（出生时被挪到空地，卡住 3 秒会瞬身到玩家身边）。
