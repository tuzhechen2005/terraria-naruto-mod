# M1 验收用例（TDD）

对应规格：[M1 波之国下忍篇](../specs/M1_波之国下忍篇.spec.md)。

状态：用例已定义，尚未执行。先让目标行为清晰、观察现状，再逐项实现和回归；不要把现有原型的行为当作验收标准。

## 测试约定

- 默认使用 tModLoader 稳定版、仅启用本模组、新角色、新世界。
- 每条用例记录版本、世界与角色、实际结果、截图或日志、结论（未执行／失败／通过）。
- 若某条用例失败，先修复对应行为，再重测该用例与受影响的既有用例。
- 标为 **阻断** 的用例全部通过，才可宣布 M1 完成。

## Red：先确认目标行为

| ID | 级别 | 操作 | 预期结果 |
| --- | --- | --- | --- |
| T01 | 阻断 | 新建角色与世界，首次进入。 | 出生点有清楚的木叶身份与任务指引，玩家获得基础战斗手段，无需开发命令。 |
| T02 | 阻断 | 完成开局训练并选择一种战斗倾向和查克拉性质，退出重进。 | 两项选择保持不变，并能在角色能力或招式上看到早期差异。 |
| T03 | 阻断 | 在本系与跨系各学习一项同阶段忍术。 | 跨系付出更多学习资源；学成后能正常造成效果，说明成本规则而非永久削弱。 |
| T04 | 阻断 | 不看攻略，按任务提示离开木叶起点。 | 玩家能找到下一片可探索区域并遭遇与波之国任务相关的敌人或线索。 |
| T05 | 阻断 | 采集资源、击败沿途敌人、查看配方并制作基础忍具与首场 Boss 道具。 | 材料均可在当前阶段取得，无须先击败任何原版 Boss。 |
| T06 | 阻断 | 仅按游戏内指引挑战白，观察并躲避各招，再击败他。 | 攻击预警与受击区域一致；玩家理解获胜方式，胜利给出下一步线索。 |
| T07 | 阻断 | 按线索挑战再不斩，分别体验斩击、水遁、雾和水分身。 | 两阶段均可读；螺旋丸不被作为此时已习得的正式剧情能力。 |
| T08 | 阻断 | 击败再不斩并保存、退出、重进。 | 出现篇章完成反馈与奖励；进度保存，后续目标正确。 |
| T09 | 阻断 | 在白和再不斩战斗中分别死亡，再次尝试。 | 任务进度不会错误跳过或锁死；必要挑战道具可重新取得。 |
| T10 | 阻断 | 从新档连续完成 T01–T08，全程不用 `/m0`、编辑器或外部攻略。 | 流程可独立完成，玩家始终知道当前目标。 |
| T11 | 非阻断 | 在主线途中自行召唤原版 Boss。 | 可选挑战仍可进行，不改变波之国章节的必需解锁条件。 |
| T12 | 非阻断 | 改变角色装备与普通武器，重复一场 Boss 战。 | 任务不强制单一配装；苦无与忍术分工仍有意义。 |

## Green：逐段实现与验证

按 T01–T05 完成开局成长和探索制作闭环，再按 T06–T09 完成两场战斗与失败恢复，最后执行 T10 的全流程测试。每完成一段，记录实际结果并更新状态；只编译成功不能将用例标为通过。
