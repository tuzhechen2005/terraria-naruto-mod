| T01 | 阻断 | 新建角色与世界，首次进入。 | 背包有苦无、忍者手册、3 颗兵粮丸；出生点有卡卡西；聊天提示 C 级任务；查克拉条显示。 |
| T02 | 阻断 | 让敌人击中自己，查看提示；按提示使用替身术。 | 提示显示当前绑定键名；待命期内受击时伤害作废，留下木头，瞬移到不卡方块的位置；冷却与查克拉消耗正确；成功后提示不再出现。 |
| T03 | 阻断 | 查克拉耗尽后，分别等待、用任一职业武器（含召唤物）攻击敌人、吃兵粮丸。 | 三种方式都能回复；命中回复每秒不超过上限；兵粮丸后出现冷却减益，期间不能连吃。 |
| T04 | 阻断 | 在地下探索，找到并使用查克拉结晶。 | 结晶可被找到；上限每枚 +20，达到 200 后不再提升。 |
| T05 | 阻断 | 与卡卡西对话，依次点“指点”“练习”；打开忍者手册；在模组设置中移动查克拉条、关闭教学提示。 | 开场白中的任务与当前进度一致；设置立即生效；练习苦无无伤害且可用替身术闪避；手册任务页和忍术页内容正确。 |
| T06 | 阻断 | 不看攻略，沿地表前往海边。 | 能遇到雾隐侦察兵、看到海边淡雾和未完成的大桥与达兹纳。 |
| T07 | 阻断 | 取得雾隐标记后在雨天或雾中探索。 | 鬼之兄弟出现，击败必掉 2 枚雾隐标记，提示任务升为 A 级。 |
| T08 | 阻断 | 集齐 3 枚标记或到达大桥。 | 迷雾预告触发一次（再不斩与白现身后离开，不战斗）；再次满足条件不重复。 |
| T09 | 阻断 | 制作挑战卷轴，在大桥上挑战并击败再不斩与白（普通与专家各一次）。 | 统一结算一次，至少一件职业武器；专家为宝藏袋；手册卷宗页解锁；装有 Boss Checklist 时可看到登记；首杀给查克拉结晶与功绩牌；大桥完工并出现告示牌；中忍考试开放。 |
| T10 | 阻断 | 同一角色再次击败两人。 | 不再给查克拉结晶与功绩牌；仍保底一件武器，面具与奖杯按概率掉落。 |
| T11 | 阻断 | 战斗中死亡再重试；丢弃卷轴后重做。 | 进度不锁死；卷轴可再做。 |
| T12 | 阻断 | 胜利后准备空房。 | 达兹纳入住并可购物；桥头不再有固定的达兹纳。 |
| T13 | 阻断 | 用含旧物品（身份卷轴、查克拉冲击等）和旧波之国进度的存档进入。 | 不报错；旧物品为未加载物品；波之国完成状态保留。 |
| T14 | 阻断 | 从新档连续完成 T01–T09，不用 `/m0`、编辑器或外部攻略。 | 流程可独立完成，玩家始终知道当前目标。 |
| T15 | 非阻断 | 在主线途中召唤原版 Boss；更换职业配装后重打。 | 原版进度与波之国互不锁；任何职业都能通关。 |
| T16 | 非阻断 | 联机两人完成替身术、迷雾预告、Boss 战与大桥完工。 | 位置、木头效果、预告与世界变化同步。 |
