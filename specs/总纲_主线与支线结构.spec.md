# 总纲：主线、支线与资源结构

状态：设计讨论定稿（2026-09-28，与用户讨论确定）；尚未实现。本文件是全模组进度结构的上位规格，各篇章的 M 规格在此框架内细化。与旧规格冲突处见文末「与现有规格的冲突」，未改稿前以本文件为准，改稿时再逐项核对。

## 核心原则

- **学灾厄的扩展方式**：原版 Boss 全部保留，不删除、不换皮；火影 Boss 插在原版 Boss 之间的进度空档中。
- **不锁原版进度**：火影主线只锁自身的链条（上一场主线终战掉落或触发下一篇章），原版 Boss 与原版进度不依赖火影内容，火影主线也不以原版 Boss 掉落为唯一门槛。
- **原版 Boss 的叙事**：保持为“这个世界本来就有的东西”，不强行写入火影剧情；只在月总等少数节点做叙事衔接。
- **玩家身份**：玩家是原创木叶忍者，与第七班同期，亲历原作事件；鸣人、佐助等原作角色保留自身身份，以 NPC、盟友或过场出现。原作中属于鸣人的决定性一击，由 NPC 在过场中接手（例：终结之谷玩家将佐助打到阈值后鸣人赶到）。剧情以 NPC 对话、Boss 登场/击败台词承载，不做重剧情线性流程。
- **城镇 NPC 入住**：卡卡西（导师）是唯一在新世界直接生成的火影 NPC；其余火影城镇 NPC 都必须满足条件（通常是完成对应篇章并有空房）后才入住。（2026-09-29 用户确认）
- **月总是阶段门槛，不是最终 Boss**：击败月总后月球封印解除，无限月读开始，进入后月总的火影终局。

### 疾风传解锁

- 条件：**击败终结之谷佐助** 且 **击败血肉墙**，两者顺序不限。第二个条件达成时全服提示“三年过去了……”，开放晓篇内容。
- 推荐顺序由难度与剧情引导：佐助难度略低于肉山，剧情上“佐助叛逃 → 修行 → 三年后”。
- 先打肉山的玩家照常进入困难模式，原版内容不受影响，晓篇等击败佐助后出现。

### 后月总（终局）

十尾人柱力带土 → 六道斑 → 辉夜（最终 Boss），三场均必打且依次解锁。另预留一个可选的终极挑战 Boss，人选未定。

### 必打主干链

```
再不斩与白 → 我爱罗 → 木叶崩溃（大蛇丸 + 万蛇）→ 终结之谷佐助
  ──【佐助 + 肉山：三年后】──
迪达拉、蝎 → 鼬 → 佩恩
  ──【月总：月球封印解除】──
十尾人柱力带土 → 斑 → 辉夜
```

可选 Boss 提供装备、材料与剧情，奖励须有吸引力，但不卡进度。

## 原作中“打不赢”的战斗

- **默认：打到阈值退场**（例如半血）。达到阈值时锁血并短暂无敌，再播放退场动画，防止爆发伤害越过阈值。
- **少数：撑过时限**，仅用于完全无法对抗的场面，全篇一到两场（如初遇鼬与鬼鲛）。
- **初遇 → 正式战**：遭遇战给少量掉落，同一角色之后的正式战才给完整奖励（死亡森林大蛇丸 → 木叶崩溃大蛇丸；寻找纲手的鼬 → 困难模式鼬）。

## Boss 体型分类

人形 Boss 的命中框保持人物尺度，难度来自机动、预警和破绽窗口；画面存在感来自术式、场地与召唤，而非放大身体（“人小招大”）。巨型 Boss 命中框大，以高血量、大范围攻击和明显预警平衡。

| 类别 | Boss |
| --- | --- |
| 纯人形 | 宁次、兜、君麻吕、音忍四人众、飞段与角都、鬼鲛 |
| 人形 + 巨型阶段/召唤/场地 | 再不斩与白（冰镜改变场地）、我爱罗（沙之巨臂）、蝎（傀儡群）、鼬（须佐能乎）、佩恩（畜生道巨兽、地爆天星）、斑（完全体须佐能乎） |
| 纯巨型本体 | 万蛇（蠕虫型分节，类似世界吞噬怪）、迪达拉的黏土巨鸟（飞行型）、十尾、辉夜最终阶段 |
| 支线巨型 | 全部尾兽与通灵兽 |

我爱罗在主线只做人形加部分尾兽化，完整巨型守鹤留给尾兽支线。

## 职业、流派与查克拉

- **职业**：沿用原版近战、远程、魔法、召唤；火影武器按伤害类型归入（大刀/体术 → 近战，苦无/手里剑/起爆符 → 远程，遁术 → 魔法，通灵术 → 召唤）。
- **流派**：跨职业的修行路线，载体为**流派核心饰品**。一次只能装备一个核心；核心提供一个消耗查克拉的热键技能、一个被动效果以及与特定武器的联动，任何职业可用；不装核心也能正常通关。核心随进度合成升级（例：写轮眼 → 万花筒写轮眼 → 永恒万花筒；妙木山修行 → 仙人模式 → 六道）。
  - 首批四个流派。每个流派分三阶（肉山前 / 困难模式 / 后月总），第一阶都在中忍考试至木叶崩溃之间取得；**每个流派都有与须佐能乎同等分量的终极形态**，各有强项，避免沦为下位替代：

    | 流派 | 第一阶来源 | 终极形态 | 强项 |
    | --- | --- | --- | --- |
    | 写轮眼 | 死亡森林大蛇丸遭遇战 | 完全体须佐能乎、轮回眼 | 防御与反击，容错最高 |
    | 八门 | 我爱罗（原作小李对我爱罗开八门） | 死门·夜凯 | 单体爆发最高，代价是持续掉血 |
    | 白眼 / 柔拳 | 宁次（可选 Boss） | 转生眼方向 | 控制与破防，提高 Boss 所受伤害 |
    | 仙术 / 九尾 | 木叶崩溃（自来也登场） | 尾兽模式（巨大九尾查克拉化身） | 续航、回复、分身 |

  - 通灵不单独成流派，由召唤职业与尾兽/通灵兽支线覆盖。
  - 流派核心与各阶升级材料都是概率掉落，需要刷。升级以 Boss 材料为主；使用熟练度最多作为次要条件，不作为主要升级途径。
- **写轮眼路线**（详细）：玩家走“移植”路线，以卡卡西为原作先例。

  | 阶段 | 形态 | 获取 | 效果方向 |
  | --- | --- | --- | --- |
  | 肉山前 | 写轮眼（一勾玉） | 死亡森林大蛇丸遭遇战掉落 | 强化替身术，判定窗口更长 |
  | 肉山前 | 二勾玉、三勾玉 | 肉山前 Boss 材料（三勾玉材料来自终结之谷佐助，二勾玉来源待定） | 三勾玉：替身成功后自动反击 |
  | 困难模式 | 万花筒写轮眼 | 迪达拉掉落的材料（原作卡卡西以神威对迪达拉） | 可取得多种瞳术技能（天照、月读、神威、加具土命等），暂不分万花筒流派；解锁肋骨形态须佐能乎 |
  | 困难模式后期 | 永恒万花筒 | 击败鼬（须佐能乎阶段）低概率掉落“鼬的写轮眼”，与万花筒合成 | 消除视力衰退；须佐能乎升为鼬式半身 |
  | 后月总 | 完全体须佐能乎 | 十尾人柱力带土掉落的材料 | 须佐能乎成长为完全体 |
  | 后月总 | 轮回眼 | 六道斑掉落 | 天手力（与目标换位）、神罗天征（推开周围一切） |

  - **视力衰退**：使用万花筒瞳术累积减益，表现为屏幕变暗、视野缩小，脱战休息后恢复。永恒万花筒消除该代价，使“打鼬取眼”成为解决实际负担的升级。
  - **须佐能乎**：肋骨（仅防御）→ 半身（防御 + 斩击）→ 完全体，按 Boss 进度分阶段解锁；开启期间持续消耗查克拉，耗尽即解除。
  - 万花筒瞳术以后可再拆分为不同流派（鼬式、佐助式、卡卡西式）。
- **五种遁术**：火、水、风、雷、土不再是开局选择，而是魔法武器系列（火遁系列、水遁系列等），玩家自由收集。旧的“战斗倾向 / 查克拉性质”由原版职业 + 流派 + 遁术系列完整取代。
- **查克拉**：独立资源，与原版魔力分开。魔法武器照常消耗魔力；查克拉供流派技能、尾兽相关能力与少数奥义级攻击使用，全职业共用。与魔力同样的使用方式：
  - **恢复**：自然恢复（慢）+ 任何职业的攻击命中回复少量查克拉（每秒有上限，防止高频武器与召唤物刷满）+ 兵粮丸（类似魔力药水，应急）。
  - **上限**：查克拉结晶永久提升上限，主要像生命水晶一样在世界中探索获得；Boss 首杀每个角色只给一次，重复击败不再掉落。肉山前有上限，困难模式出现更高一阶材料（类似生命果）继续提升。
- **替身术**：全职业通用的基础忍术，热键释放，是玩家第一个查克拉技能，详见 M1 规格。流派可强化它（例：写轮眼延长判定窗口）。
- **“术”而非法杖**：魔法与召唤武器的物品就是忍术本身（例：“水遁·水龙弹之术”“秘术·魔镜冰晶”），图标为结印或卷轴，使用时播放结印动作，照常消耗魔力。模组内不出现法杖。

## 尾兽支线

- **定位**：可选收集线，每只尾兽是所在阶段偏难的 Boss。不收集尾兽不影响打主线 Boss。
- **召唤材料**：
  1. **尾兽残留查克拉**：只在特定时间/条件下生成的专属怪物掉落，掉率很低（例：守鹤的材料怪只在沙暴时出现）。
  2. **人柱力线索 / 封印卷轴**：通过挑战获得，可与追捕该尾兽的可选晓成员战斗关联（例：二尾线关联飞段与角都）。
  3. 两者合成封印祭坛，在对应生物群系使用召唤尾兽 Boss。
- **奖励**：
  - **尾兽契约**：就是一件普通召唤武器，与双子魔眼法杖等原版召唤杖相同——召唤伤害、占用召唤栏位、按原版规则叠加。强度对标同期召唤物，攻击不高；每只尾兽有独特辅助特性（例：守鹤以砂防御为玩家附加护盾）。
  - **迷你尾兽宠物**：纯装饰。
  - 集齐九只的终极奖励（候选：六道之力流派或尾兽查克拉外衣），待定。
- **分布（初稿）**：一尾守鹤（沙漠，肉山前、我爱罗之后）；二尾又旅（地下，困难模式初期）；三尾矶抚（海洋，机械三王期）；四尾孙悟空（地狱，机械三王后）；五尾穆王、六尾犀犬（世纪之花后）；七尾重明（丛林，石巨人后）；八尾牛鬼（海洋/雷暴，猪鲨期）；九尾（后月总）。
- **九尾的特殊规则**：击败月总后开放；召唤需集齐阴、阳两份九尾查克拉，不要求先收集其他八尾。阴阳查克拉的具体获取方式待定。

## 通灵兽支线

比尾兽轻：获取难度与强度都更低，以辅助为主，可作为前期召唤流的入门（蛤蟆、蛇、蛞蝓）。具体获取方式待定。
