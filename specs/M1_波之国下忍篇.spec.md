# M1 规格：波之国下忍篇

状态：开发中。固定挑战顺序已由 `M1_自由探索与再不斩战斗重构.spec.md` 修订；数值、台词和场景表现可在试玩中调整。

## 一句话目标

玩家创建一名自创忍者，从新角色和新世界出发，在保留 Terraria 探索、采集、制作的过程中，自然参与波之国事件，自主决定白与再不斩的挑战顺序，完成第一个可独立游玩的火影篇章。

## 已确定的设计基准

- 玩家是自创忍者，参与《火影忍者》原作事件；鸣人等原作角色保持自己的身份。
- 火影任务负责主线推进。原版 Boss 可作为可选挑战，不能成为忍具或章节解锁的唯一门槛。
- 战斗采用普通攻击与忍术配合：普通攻击维持交手并帮助恢复查克拉，忍术用于抓住空档和改变局面。
- 开局选择战斗倾向及一种基础查克拉性质。后续允许跨系学习，跨系学习成本更高；学成后的招式不应永久残缺。
- 人形 Boss 保持人形尺度。判定与画面一致，难度来自招式预警、移动、控场和反击时机。
- M0 的“螺旋丸打再不斩”仅用于测试手感，不写入 M1 正式剧情。

## 玩家路径

1. **成为下忍**：进入可识别的木叶起点，获得任务指引、基础武器和查克拉能力；完成简短训练，确定战斗倾向与查克拉性质。
2. **接下任务**：从任务指引获知波之国方向和当前目标；任务信息在死亡、退出和重进后可继续查看。
3. **调查雾忍**：离开起点探索，在可到达的区域遭遇雾隐敌人，取得情报和制作材料。
4. **准备挑战**：采集木材、矿石等资源，制作基础忍具与进入首场 Boss 战所需的道具；流程不能依赖原版 Boss 掉落。
5. **挑战白**：学习其招式与反击窗口，击败后获得进入再不斩战斗的线索或道具。
6. **挑战再不斩**：面对斩击、水遁和第二阶段的雾与水分身；胜利后得到明确的篇章完成反馈和奖励。

## 必须满足的行为

| 编号 | 需求 | 可观察的结果 |
| --- | --- | --- |
| R1 | 新档引导 | 玩家不查外部攻略、不用 `/m0`，能在游戏里知道下一步去哪、做什么。 |
| R2 | 成长选择 | 战斗倾向与基础性质可由玩家选择、会保存；选择带来可感知的早期差异。 |
| R3 | 跨系规则 | 至少通过一项可获取的跨系忍术验证“学习成本高、练成后可正常使用”。 |
| R4 | 采集制作 | 至少一条从探索资源到忍具、再到 Boss 挑战的制作链完整可用。 |
| R5 | 白的战斗 | 白有区别于再不斩的节奏，关键攻击有预警和可解释的躲避方式。 |
| R6 | 再不斩战斗 | 斩击、水遁、雾和水分身能构成可读的两阶段战斗。 |
| R7 | 进度保存 | 任务、选择及 Boss 击败状态在保存并重进后正确恢复。 |
| R8 | 失败可恢复 | 死亡、丢失普通任务道具或挑战失败后，玩家能在游戏内重新获得必要道具并重试。 |
| R9 | 原版兼容 | 原版 Boss 不挡住波之国主线；玩家仍可自行挑战原版内容。 |

## 范围边界

M1 的目标是**单人模式下完整可玩的一章**。地图、美术和台词需要足以说明木叶起点与波之国事件，但不要求完整重建火影世界。M1 不要求完成全部五系高阶技能树、中忍考试、困难模式阶段转换或多人同步；这些另立规格。

开发期间可保留 `/m0` 测试入口，但验收时必须使用新角色和新世界，从游戏内正常流程完成。

## 完成定义

只有在 `tests/M1_波之国下忍篇.acceptance.md` 中所有阻断级用例通过，且至少一次从新档到篇章结束的完整试玩没有外部干预时，M1 才可标为完成。编译通过或单独击败两名 Boss 不等于完成本阶段。
