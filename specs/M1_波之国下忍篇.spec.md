# M1 规格：波之国下忍篇（2026-09-29 重写并补充）

状态：设计定稿，按「实施阶段」逐步改代码。上位规格为 `specs/总纲_主线与支线结构.spec.md`；Boss 战本身以 `specs/M9_波之国双首领战.spec.md` 为准。旧版“战斗倾向 / 查克拉性质 / 忍术研习手册”设计已作废，旧内容见 Git 历史。数值为初始值，按试玩调整。

## 阶段目标

玩家以原创木叶忍者身份开局，在正常的 Terraria 探索、采集、制作中接触查克拉与替身术，追查雾隐忍者，挑战再不斩与白（M9 双首领战）。难度对标克苏鲁之眼前后，不以任何原版 Boss 为门槛。

- **游玩时长目标**：专注主线约 1.5 小时；与原版开荒交错约 2–3 小时，与原版“开局到克眼”同步，不另占大块时间。
- **叙事对照**（原作波之国篇 → 本模组）：护送达兹纳 → 开局任务；鬼之兄弟伏击 → 精英敌人；湖边初遇再不斩、白假扮追杀部队带走他 → 迷雾预告；大桥决战 → M9 双首领战；大桥完工、命名“鸣人大桥” → 胜利后世界变化。

## 开局

- 新角色获得：**苦无**（远程投掷武器，不消耗）、**忍者手册**（取代任务卷轴）、3 颗**兵粮丸**。

## NPC

- **卡卡西**（木叶城镇 NPC，导师）：
  - 新世界在出生点直接生成；旧世界加载时若不存在也在出生点生成；死亡后像向导一样重生。**这是唯一直接生成的火影 NPC；其余火影城镇 NPC 都必须满足条件后才入住。**
  - 对话：开场白里用卡卡西的口吻说出当前任务；按钮“指点”（轮流讲替身术、查克拉、兵粮丸等）、“练习”（向玩家投一支无伤害训练苦无，供当场练替身术）。tModLoader 原生只支持两个对话按钮，故“任务”并入开场白。
  - 后续篇章由他发布任务。
- **达兹纳**（造桥工）：
  - 胜利前：固定站在大桥旁小屋，不入住城镇，类似地牢老人；对话讲波之国困境、卡多与雾隐。
  - 胜利后：离开桥头，满足条件（波之国完成 + 有空房）后入住城镇，成为商人（木材类建材、兵粮丸、“鸣人大桥”纪念家具等，商品表待定）。
- 鸣人、佐助、小樱、卡多：M1 只在台词中出现，不做 NPC。

## 世界与地形

不新增完整生物群系；以原版海洋 / 海滩承载波之国。

| 区域 | 内容 |
| --- | --- |
| 森林地表（出生点） | 卡卡西、苦无与替身术上手 |
| 远离出生点的地表 | 雾隐侦察兵（距出生点 850 像素以上） |
| 海滩 / 海洋边缘 | 侦察兵增多、海边淡雾、鬼之兄弟、大桥 |
| 雨天 / 夜晚 | 侦察兵与鬼之兄弟出现率提高 |
| 地下层 | 查克拉结晶 |

**未完成的大桥**（世界生成结构）：

- 在一侧海边生成一座伸向海面、断在半截的木桥，配达兹纳小屋与码头；全部用原版木材、平台、绳索等图块，不需要新图块美术。
- 桥面上方开阔、长度足以展开冰镜牢笼。
- 老世界没有大桥：由卡卡西或手册提供兜底（例如在海边指定位置补建），实现时确定；不影响主线可完成。
- **大桥完工**：波之国首次完成后，断桥自动补齐，桥头出现“鸣人大桥”告示牌。

## 查克拉

- 独立资源，与原版魔力分开，全职业共用；HUD 显示查克拉条。
- 初始上限 100。
- **恢复**：
  - 自然恢复：慢速（初始：施术后 5 秒内每秒 3 点，其后每秒 10 点，沿用现有实现）。
  - 命中回复：任何职业的攻击命中敌人回复少量查克拉，每秒回复总量有上限（初始每秒最多 5 点）；召唤物命中同样计入并受同一上限约束。
  - **兵粮丸**：早期材料可合成，食用后立即回复查克拉，并附带类似“魔力病”的短暂冷却减益，防止连吃。
- **查克拉结晶**：永久提升上限（初始每枚 +20）。
  - 主要来源：像生命水晶一样生成于地下，需探索与挖掘取得。
  - 波之国 Boss 首次击败时每个角色给一枚，重复击败不再掉落。
  - 肉山前上限封顶（初始 200）；更高阶的提升材料留待困难模式。

## 替身术（基础忍术）

全职业通用，开局即可用，热键释放（默认键实现时核对不与原版冲突，可在按键设置中修改），是玩家的第一个查克拉技能。

1. 按下热键：消耗查克拉（初始 20），进入约 0.4 秒的“替身待命”。
2. 待命期间受到伤害：伤害作废，原地留下一截木头的视觉效果，玩家瞬移到附近不卡方块的安全位置，获得短暂无敌。
3. 待命期间未受伤害：待命结束，已消耗的查克拉不返还。
4. 无论成功与否都进入冷却（初始约 4 秒）；查克拉不足或冷却中按键无效，并有提示。

实现要点：用 tModLoader 的 `ModPlayer.FreeDodge` 作废伤害；落点需做方块碰撞检查，找不到安全点时原地闪避；联机同步位置与木头效果。写轮眼等流派将来可延长判定窗口或追加反击。

**教学（三层）**：

1. **实战提示**：玩家被敌人击中且查克拉足够时，屏幕提示“按【键名】施展替身术，在受击前一刻使用可完全闪避”，键名实时读取按键设置；最多出现 3 次，首次替身成功后不再出现。
2. **卡卡西“练习”**：安全环境中反复练习。
3. **忍者手册“忍术”页**：随时查阅。

## 主线流程

1. **出发**：开局提示任务；卡卡西可询问目标。
2. **海边迷雾**：沿地表探索，遭遇雾隐侦察兵，收集**雾隐标记**；靠近海边出现淡雾。
3. **鬼之兄弟**：首次取得雾隐标记后，雨天或雾中可能出现精英敌人鬼之兄弟（一对，锁链相连，夹击），击败必掉 2 枚雾隐标记与少量钱币，提示“任务等级上调为 A 级”。
4. **迷雾预告**：集齐 3 枚标记或首次到达大桥时（每个世界一次），浓雾中再不斩立于水面留下台词，白戴追杀部队面具现身将他带走后消失；不发生战斗。手册任务更新为“制作挑战卷轴，到大桥上了结”。
5. **大桥决战**：在工作台制作**再不斩挑战卷轴**（可重复使用，丢失可再做）。卷轴任何地方可用；在大桥上使用时有专属浓雾与台词。挑战 M9 双首领战，两人都击败才算通关，记录波之国完成，大桥完工，开放中忍考试（M2），手册暗示死亡森林。

## 波之国 Boss 奖励

两人都倒下后算一次击败，**统一结算一次**，掉落位置在最后倒下的 Boss 处。2026-09-29 改为保底制（原“四把武器各 25% 独立判定”约有 32% 概率一件不掉）。

**普通模式（直接掉落）/ 专家与大师模式（宝藏袋内）**：

| 物品 | 掉落 |
| --- | --- |
| 四职业武器：斩首大刀（近战）、千本（远程）、水遁·水龙弹之术（魔法）、秘术·魔镜冰晶（召唤冰镜发射千本） | **保底四选一**；另有约 20% 概率再给一件不重复的 |
| Boss 面具：再不斩护额、白的面具 | 各约 1/7（原版 Boss 面具规则） |
| 查克拉结晶 | 每个角色仅首次击败给一枚（不进宝藏袋，单独掉落） |
| 波之国功绩牌 | 每个角色首次击败必掉 |
| 专家专属饰品 | 仅宝藏袋，必出；具体物品随“补充道具”讨论确定 |

**纪念品**：战利品奖杯（再不斩、白各一，约 10%）；大师模式遗物（必掉）。

强度：Boss 武器略强于金 / 铂金武器，弱于魔矿 / 猩红矿武器。

另可合成一件初级水遁（例：“水遁·水乱波”），作为魔法职业在打 Boss 前的选择。所有魔法 / 召唤武器都是“术”：图标为结印或卷轴，使用时播放结印动作，消耗魔力；不出现法杖。

补充道具（手里剑、起爆符、木叶护额、鬼之兄弟掉落等）**待与用户讨论**，未定前不实现。

## 模组设置与引导

- **模组设置**（客户端）：查克拉条位置（水平、垂直偏移）；是否显示替身术的教学提示。
- **Boss Checklist 支持**：若玩家装有 Boss Checklist 模组，登记“再不斩与白”：进度位置在克苏鲁之眼附近，写明召唤物（再不斩挑战卷轴）、召唤方式与掉落。未安装时不影响任何功能。
- **不引入其他内容模组的专属内容**（例如不做与灾厄海洋群系的联动）。
- **原创音乐**：以后考虑为“波之国迷雾”“大桥决战”制作原创曲；不得使用火影原声。
