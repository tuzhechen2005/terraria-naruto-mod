# M2a 规格：木叶村与地区背景

状态：2026-09-30 与用户讨论定稿，实现中。上位规格为 `specs/总纲_主线与支线结构.spec.md` 末尾“地区与村庄”。这是 M2（中忍考试）的第一部分：木叶是中忍考试与之后篇章的舞台。

## 用户已决定

- **木叶是唯一的完整城镇**：能走进去逛、有 NPC 生活，房间数量约 **45 间**（原版城镇 NPC 约 26 + 城镇宠物 3 + 城镇史莱姆 8 + 火影 NPC 余量）。
- **位置**：以出生点为中心。**阿吽大门立在出生点正上方**，是村子的中心地标；主街穿过大门，村子向左右两侧展开。
- **火影岩只画在背景图里**，不用方块堆山。
- **只在新世界生成**；旧世界没有木叶（不做施工图）。
- **只用原版图块**，不需要新图块美术。
- **其他村子**不做完整城镇：挂在原版生物群系上，以专属背景（以后加小地标、BGM、怪物）体现。
- **背景图**（每个三层视差：远景、中景、近景）：木叶、雾隐/波之国、砂隐、雨隐、雪之国、草隐/泷隐、岩隐、妙木山。当前够用；腐化/猩红（音隐）、神圣、地狱等困难模式地区以后再议。

合计 **48 间**，全部按原版规则可入住（后台服务器在小、中、大世界各生成验证，48/48 通过原版 `StartRoomCheck` + `RoomNeeds` + `ScoreRoom`）：有背景墙、门或平台入口、光源（灯笼）、桌子与椅子；上层房间以楼板里的平台进出。

- **木叶区域**记在世界数据里（中心、地面、半宽），供背景、生物群系与幸福度使用。
- **幸福度**：新增“木叶”生物群系，所有原版城镇 NPC 都“喜欢”住在木叶；木叶是规划好的村子，家在木叶里的 NPC **不计“拥挤”惩罚**（钩住原版统计附近居民的方法，只对木叶内的 NPC 生效），这样住满 45 间也不会涨价、仍可买晶塔。
- 卡卡西照旧生成在出生点（大门下）。

## 验收

- 自动：布局规则测试（房间数 ≥ 45、每间满足原版住房尺寸、建筑互不重叠、全部在 ±193 内）；后台服务器生成新世界后导出木叶区域，逐间用原版 `WorldGen.StartRoomCheck` 验证可入住，并用原版贴图渲染预览图检查。
- 手动（实机）：新建世界出生在大门下；村子外观；NPC 入住与幸福度；各地区背景显示与切换；模组设置开关。
