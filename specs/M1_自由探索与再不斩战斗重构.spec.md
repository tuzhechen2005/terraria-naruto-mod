# M1 修订规格：自由探索与再不斩战斗样板

状态：开发中。本文件修订 `M1_波之国下忍篇.spec.md` 的固定挑战顺序；原规格其余目标继续有效。

## 玩家自由

- 训练是获得基础奖励的成长路线，不是侦察兵生成或 Boss 卷轴使用的前置条件。
- 地表探索可获得雾隐标记；白和再不斩的可重复使用挑战卷轴都能用这些材料制作，任意顺序挑战、失败后重试。
- 任务卷轴只列出可选线索、两名 Boss 独立进度和奖励方向，不自动指定唯一“下一步”。
- 白与再不斩都是必须击败的主线 Boss：两名 Boss 都击败才记录波之国完成并开放中忍考试，但章节内挑战顺序不限；既有世界的击败标记不清零。
- 普通游戏不依赖 `/m0`。测试卷轴仍作为调试入口。

## 再不斩战斗样板

- 人形尺寸保持 30×50 像素；身体接触不造成伤害。
- 不画矩形危险区或行进路线。斩击靠持刀蓄势、挥刀动作及声音辨认；水遁靠结印姿态、水声与可见飞行体辨认。出招方向在动作开始时锁定，不在最后一刻追踪玩家。
- 斩击的有伤判定只覆盖挥出刀身所在的窄区与短时间，不用半透明矩形模拟刀光；水遁使用独立像素飞行体，碰撞盒与弹体主体接近。
- 每次攻击经历准备、攻击、收招；收招留出反击窗口。动作、音效与弹道而非 UI 提示承担读招功能。
- 半血时有明确的阶段过渡、雾与水分身演出；分身与本体在颜色上可区分。本体的攻击节奏/组合发生变化。
- Boss 血条沿用原版布局和生命值表现，仅用本体肖像识别；不添加阶段刻线、阶段文字或额外色条。分身不计入本体生命值。
- 胜利反馈区分“击败再不斩”和“两名 Boss 均击败”；存档后进度不丢失。

## 边界

本轮以再不斩为 Boss 战标准样板，不声称白和中忍考试 Boss 已达到同等质量。美术以现有像素角色为基础，新增蓄刀、挥刀、结印三种关键动作和水遁弹体；完整逐帧过渡动画另列后续美术工作。编译与规则测试不是实机手感验收。
