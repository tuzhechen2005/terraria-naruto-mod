# M9 波之国再不斩与白双首领战

状态：代码与素材已实现、自动测试通过；实机验收待复核。

## 决策

- 一阶段只有再不斩。到半血后完成鬼人转场，白在转场中登场但不会在转场结束前攻击。
- 两人各有独立生命值，血条使用 tModLoader 原版首领血条与头像，不额外自绘 UI。再不斩负责冲撞与水系主攻；白负责高速牵制、冰镜与少量千本。强招错峰，不叠加不可躲的密集弹幕。
- 白血量 500–600，整体难度对标克苏鲁之眼级别、需要一定前期装备。任意一方先死，另一方获得独特的暴走动作与节奏；不以单纯翻倍弹幕实现。
- 必须同一场击败二人才算通关。单人死亡或离开造成战斗失败时，两人都不计进度；下次从再不斩一阶段重开。最后一人死亡才发主线完成奖励。
- 取消白单独卷轴与配方；旧白卷轴在玩家背包中转换为再不斩卷轴，旧存档已双通关保留，单人通关标志作废。M0 测试卷轴也进入新战斗。
- 白的像素造型以《火影忍者》原作波之国篇为参考重新制作：白面具红纹、深色长发、青绿色衣袍；独立战斗姿势、面部特写与冰镜效果。只生成原创模组素材，不复制官方图。

## 安全与平衡约束

- 白的近身冰镜移动与再不斩的大型水弹、弹幕雨、螺旋、冲撞错峰；留可见蓄力与反击时间。
- 白偶尔施展冰镜空间：只在两人都存活、再不斩未进行强招时开始；先显示四向冰镜和施术动作，再让两人短暂隐身并停止普通攻击。四个方向依次各来一枚大冰锥，每枚先在出发点亮起预警，再飞向玩家当时的位置；不追踪、不同时铺满屏幕。结束有恢复窗口，冷却后才可再次施展。
- 冰镜空间开始/结束由白的 AI 状态同步，再不斩读取该状态暂停和恢复自身攻击。若一方死亡或战斗中止，镜域立即取消，不留下隐身状态或继续生成弹幕。
- 常规冰千本放大并加亮轮廓和飞行尾迹，危险区域与视觉对应。双首领战攻击伤害整体仅小幅下降，不能用大幅削弱掩盖弹幕辨识问题。
- 联机只由服务端召唤白和生成弹体；死亡、强化、进度同步。离开战斗不掉落奖励。
- 血条展示遵循原版首领 UI 选择与布局规则，不覆盖原版样式。

## 验收

- 先写规则测试：召唤时序、单场双击败结算、旧档兼容、白的弹幕上限与错峰、双方暴走幅度。
- 自动：规则测试、全模组构建、像素素材、原版血条接入与头像检查。
- 手动：一阶段/二阶段、两种先后击杀、玩家死亡重开、联机、旧卷轴迁移、画面可读性及克眼级别难度。未实机运行不能标记通过。
- 手动补测：镜域出现频率、四向预警是否足以判断来向、冰锥命中后是否消失、两人现身后的反击窗口，以及冰千本在明暗背景中的可见度。
