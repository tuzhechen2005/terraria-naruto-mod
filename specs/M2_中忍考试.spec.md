# M2 规格：中忍考试·森林试炼与预选赛

状态：开发中；M1 的游戏内验收仍未完成，不以 M2 的构建结果替代。

## 阶段目标

玩家完成波之国篇后，以自己的忍者身份报名中忍考试，在 Terraria 丛林完成“天、地卷轴”生存试炼，制作预选赛挑战凭证，战胜一名原创砂隐考生，取得明确的中忍晋升反馈与奖励。整条路线从游戏内任务卷轴可读，不需要开发命令，也不以原版 Boss 为门槛。

这是中忍考试的可玩改编章节，不重排鸣人等原作人物的既定对战；本阶段不制作完整的笔试 UI、原作全体参赛者或木叶崩溃事件。

## 玩家路径与边界

1. 波之国篇完成后，任务卷轴提示制作并使用报名书；未完成波之国的世界不能报名。
2. 报名后前往天然丛林。地表试炼敌人必掉“天之卷轴”，地下丛林试炼敌人必掉“地之卷轴”，避免纯随机掉落导致锁关。
3. 用两种卷轴和可在当前阶段取得的普通材料制作预选赛挑战书。丢失后可重新探索和制作。
4. 在开阔地挑战原创砂隐考生。其战斗节奏包含远距离沙弹、近距离突袭和明显的蓄力／恢复窗口，身体保持人形尺度。
5. 胜利后显示晋升反馈，掉落中忍护额奖励；世界完成标记与角色试炼进度保存。

M2 首先验收单人模式。沿用 M1 的战斗倾向、查克拉性质、跨系学习与装备自由，不新增永久重选或洗点规则。

## 可观察需求

| 编号 | 需求 | 可观察结果 |
| --- | --- | --- |
| E1 | 前置门槛 | 未击败再不斩无法报名；完成后任务卷轴指引报名。 |
| E2 | 自然引导 | 玩家知道丛林地表、地下分别要取得什么。 |
| E3 | 双卷轴试炼 | 两类试炼敌人可自然遭遇，击败各自稳定掉落对应卷轴。 |
| E4 | Terraria 资源链 | 用双卷轴与普通资源制作挑战书，不依赖原版 Boss。 |
| E5 | 预选赛 Boss | 人形砂隐对手至少有两类招式，预警与判定相符，存在反击窗口。 |
| E6 | 失败恢复 | 死亡、挑战失败、普通试炼物品丢失后可重试，无一次性锁关。 |
| E7 | 存档一致性 | 报名、试炼、击败记录和晋升目标保存重进后正确。 |
| E8 | 奖励 | 胜利反馈明确，奖励能正常装备并影响早期玩法。 |
| E9 | 美术同步 | 报名书、双卷轴、试炼敌人、预选对手、护额有项目内可用素材；招式危险区域可读。 |

## 完成定义

`tests/M2_中忍考试.acceptance.md` 中全部阻断用例在实际游戏内通过，且从一个完成 M1 的存档不用开发命令连续通关 M2，才可将 M2 标为完成。仅规则测试、静态资源检查和编译通过不等于验收完成。
