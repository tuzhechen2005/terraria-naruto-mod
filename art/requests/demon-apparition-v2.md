# 素材请求：demon-apparition-v2

- 状态：requested
- 提出者及提交号：Claude Code，鬼人化特效样稿第 2 轮
- 背景：v1（`art/deliveries/demon-apparition-v1/`）的紫色、火焰质感、帧结构和尺寸都可以，但**造型像西方恶魔**（蝙蝠状的宽角、扁宽的恶魔脸）。用户要的是**日本般若（Hannya）面具**式的鬼。
- 本次要求：保持 v1 的紫色查克拉火焰呈现方式与帧结构，把鬼脸换成般若造型：
  - 额头两侧长出一对**细长、尖锐、向上后方弯曲的角**（像般若面具的角，不是蝙蝠翼状的宽角）。
  - **眉头紧锁上挑**，眉间深皱，眼神怨怒；眼睛细长上吊，发亮（亮粉白或淡金）。
  - **嘴从一侧耳根咧到另一侧**，嘴角大幅上扬，上下两排尖牙与獠牙外露——般若最标志的狰狞笑口。
  - **脸型细长**：整体比 v1 窄、更高，下巴收尖；像能剧面具的脸型，而不是圆宽的兽脸。
  - 头发/火焰从脸两侧与头顶向上飘散，下方收拢成火焰柱连向人物。
  - 颜色：深紫黑外缘 → 紫 → 品红 → 亮粉白（眼、牙、火焰尖），不要红色。
- 画风与规格同 v1：像素画，最终每美术像素 = 2×2 屏幕像素，硬边色阶，无抗锯齿；最终约 **80×100 个美术像素**（比 v1 的 88×96 更细长）；按每美术像素 8×8 屏幕像素绘制。
- 帧数：循环 4 帧 + 浮现 3 帧，同 v1；每行最左边放同画布大小的纯色基准矩形。附一张 game-size sheet（每美术像素 1 屏幕像素）。
- 参考（必须打开看）：`art/reference/demon_mode_ingame.png`、`art/reference/demon_mode_cg.png`（气势与颜色）；v1 样稿（质感与帧结构）。般若面具造型按上面文字描述。只作参考，不得复制。
- 需要避免的问题：西方恶魔/魔王造型、蝙蝠翼角、圆宽的脸、红色。
- 验收：一眼看出是日式般若鬼面，叠在再不斩身后气势接近参考截图。
